# StreamLens Pro

ส่วนขยาย Chrome สำหรับตรวจจับ URL ของวิดีโอและสตรีมที่หน้าเว็บเรียกใช้งาน พร้อมคัดลอก URL ดาวน์โหลดไฟล์สื่อโดยตรง หรือสร้างสคริปต์ Windows สำหรับใช้ FFmpeg ดาวน์โหลดสตรีม

> เครื่องมือนี้ตรวจจับ URL จากการตอบกลับของเครือข่าย ไม่ได้ปลดล็อก DRM หรือข้ามระบบควบคุมการเข้าถึง โปรดใช้กับสื่อที่คุณมีสิทธิ์เข้าถึงและดาวน์โหลดเท่านั้น

## ความสามารถ

- ตรวจจับสื่อจากชนิดเนื้อหาและนามสกุล URL เช่น MP4, MP3, HLS (`.m3u8`) และ DASH (`.mpd`)
- แสดง URL ที่ตรวจพบในหน้าต่างส่วนขยาย พร้อมคัดลอก URL
- ดาวน์โหลดไฟล์สื่อโดยตรงผ่าน Chrome
- สร้างไฟล์ `.bat` สำหรับ FFmpeg เพื่อดาวน์โหลด HLS/DASH หรือรวม URL แทร็กภาพและเสียงที่ตรวจพบ
- กรอง URL บางรายการด้วยรูปแบบคีย์เวิร์ดโฆษณาที่กำหนดไว้ในส่วนขยาย

## ความต้องการ

- Google Chrome ที่รองรับ Manifest V3
- Windows สำหรับเรียกใช้ไฟล์ `.bat` ที่ส่วนขยายสร้าง
- FFmpeg เมื่อต้องการดาวน์โหลดสตรีมหรือรวมแทร็ก โดยติดตั้งให้เรียกใช้ `ffmpeg` จาก `PATH` หรือวาง `ffmpeg.exe` ไว้ที่ `C:\ffmpeg\bin\ffmpeg.exe` หรือโฟลเดอร์เดียวกับไฟล์ `.bat`

## ติดตั้งใน Chrome

1. ดาวน์โหลดหรือ clone โฟลเดอร์โปรเจกต์นี้ไว้ในเครื่อง
2. เปิด `chrome://extensions`
3. เปิด **Developer mode** ที่มุมขวาบน
4. เลือก **Load unpacked**
5. เลือกโฟลเดอร์โปรเจกต์ที่มี `manifest.json`

## วิธีใช้งาน

1. เปิดหน้าเว็บที่มีสื่อที่คุณได้รับอนุญาตให้เข้าถึง
2. กดเล่นวิดีโอหรือเสียงสักครู่ เพื่อให้หน้าเว็บเริ่มเรียกข้อมูลสื่อ
3. เปิด StreamLens Pro จากแถบเครื่องมือ Chrome
4. หากรายการยังไม่ปรากฏ ให้กด **รีเฟรช** เพื่อดึงรายการที่ตรวจพบแล้วมาแสดงอีกครั้ง
5. เลือก **คัดลอก URL**, **บันทึกไฟล์** หรือปุ่มดาวน์โหลดสตรีมตามชนิดรายการ
6. หากดาวน์โหลดเป็นไฟล์ `.bat` ให้เปิดไฟล์นั้นบน Windows หลังตรวจสอบแหล่งที่มาและเนื้อหาของไฟล์แล้ว โดยต้องติดตั้ง FFmpeg ตามข้อกำหนดด้านบน

ปุ่ม **รีเฟรช** ใช้โหลดรายการที่ส่วนขยายเก็บไว้มาแสดงใหม่เท่านั้น ไม่ได้รีโหลดหน้าเว็บหรือสั่งให้เริ่มตรวจจับสื่อใหม่

## ข้อจำกัด

- การตรวจจับทำงานเมื่อมีการตอบกลับเครือข่ายที่ส่วนขยายมองเห็น สื่อที่ยังไม่เริ่มโหลดหรือใช้วิธีส่งข้อมูลที่ไม่ตรงกับรูปแบบที่ตรวจจับอาจไม่ปรากฏ
- การจับคู่แทร็กภาพและเสียงเป็นการเลือกจากรายการที่ตรวจพบ ไม่ได้รับประกันว่าเป็นรายการจากวิดีโอเดียวกันทุกกรณี
- การดาวน์โหลดอาจล้มเหลวเมื่อ URL หมดอายุ ต้องใช้คุกกี้หรือส่วนหัวอื่น หรือเซิร์ฟเวอร์ปฏิเสธคำขอจาก FFmpeg
- ส่วนขยายไม่รองรับการถอดรหัส DRM
- ตัวกรองโฆษณาใช้รูปแบบ URL และคีย์เวิร์ด อาจกรองสื่อที่ URL มีคำตรงกับตัวกรองโดยไม่ตั้งใจ และไม่สามารถรับประกันว่าจะกรองโฆษณาได้ทั้งหมด
- ไฟล์ดาวน์โหลดโดยตรงจะตั้งนามสกุลตามชนิดที่ส่วนขยายจำแนก ไม่จำเป็นต้องตรงกับรูปแบบจริงของทุก URL

## สิทธิ์ที่ใช้

ค่าที่กำหนดใน `manifest.json`:

- `webRequest` และ `host_permissions: ["<all_urls>"]` ใช้ตรวจดู URL และส่วนหัวการตอบกลับจากหน้าเว็บ
- `downloads` ใช้ดาวน์โหลดสื่อและไฟล์ `.bat`
- `tabs` ใช้ระบุแท็บปัจจุบันและเชื่อมรายการสื่อกับแท็บ
- `activeTab` และ `storage` ถูกประกาศเป็นสิทธิ์ของส่วนขยาย

ส่วนขยายเก็บรายการสื่อไว้ในหน่วยความจำของ service worker แยกตามแท็บ รายการจะถูกล้างเมื่อปิดแท็บหรือเริ่มโหลดหน้าใหม่ และสามารถล้างได้จากปุ่ม **ล้างรายการ**

## โครงสร้างไฟล์

- `manifest.json` — การตั้งค่าและสิทธิ์ของส่วนขยาย
- `background.js` — ตรวจจับและจัดเก็บรายการสื่อที่พบ
- `popup.html`, `popup.css`, `popup.js` — หน้าต่างแสดงผลและการดำเนินการกับรายการสื่อ
- `backend.js` — ชุดรูปแบบ URL สำหรับกรองโฆษณาแยกต่างหาก (ไม่ได้ถูกโหลดโดย `manifest.json` ในการตั้งค่าปัจจุบัน)

## การแก้ปัญหาเบื้องต้น

**ไม่พบสื่อ**

- เริ่มเล่นสื่อสักครู่แล้วเปิดส่วนขยายอีกครั้ง
- กด **รีเฟรช** หลังสื่อเริ่มโหลด
- ตรวจสอบว่าหน้าเว็บไม่ได้บล็อกการเข้าถึง หรือสื่อไม่ได้ใช้ DRM

**ไฟล์ `.bat` แจ้งว่าไม่พบ FFmpeg**

- ติดตั้ง FFmpeg และเพิ่มลงใน `PATH` หรือวาง `ffmpeg.exe` ตามตำแหน่งที่ระบุในหัวข้อความต้องการ
- เปิด Command Prompt แล้วเรียก `ffmpeg -version` เพื่อตรวจสอบการติดตั้ง

**FFmpeg ดาวน์โหลดไม่ได้**

- URL สตรีมอาจหมดอายุหรือจำเป็นต้องใช้การยืนยันตัวตน/ส่วนหัวเพิ่มเติม
- ลองตรวจจับ URL ใหม่หลังเริ่มเล่นสื่ออีกครั้ง
- ตรวจสอบว่าเซิร์ฟเวอร์อนุญาตการเข้าถึงจาก FFmpeg
